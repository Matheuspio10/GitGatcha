# Translating GitGacha (English + Brazilian Portuguese)

Guide used for the PT-BR rounds (PR #55 onwards), for whoever translates a screen, person or agent.

The project uses **next-intl 4** without URL prefixes (the locale is a cookie). Infra is done:
- `src/i18n/locales.ts`, `src/i18n/request.ts`, `src/i18n/messages.ts` (static imports of `messages/<locale>/<namespace>.json`), `src/i18n/global.d.ts` (keys are TYPED from the English JSON: a wrong key fails `tsc`).
- The root layout wraps everything in `NextIntlClientProvider`.
- Reference conversion already done: `src/components/Navbar.tsx` + `messages/en/nav.json` + `messages/pt-BR/nav.json`. Read them first and follow the same style.

## The job
Move the user-facing text of a screen into its namespace JSON files (both `messages/en/<ns>.json` and `messages/pt-BR/<ns>.json`). Namespaces in use: nav, common, store, inventory, collection, forge, onboarding, notifications. Part 2: battle, teamBuilder, leaderboard, social, profile, public. Part 3: game, wiki.

## How
- Client components (`'use client'`): `import { useTranslations } from 'next-intl'; const t = useTranslations('<ns>');` (or a sub-path like `useTranslations('<ns>.section')`). For helper functions outside components, pass `t` in or move the text into the component.
- Server components / pages: `import { getTranslations } from 'next-intl/server'; const t = await getTranslations('<ns>');`. `generateMetadata` can use it too.
- Keys: camelCase, nested by screen section (`purchase.title`, `missions.reroll`). English values must be EXACTLY the current English text (no rewording, no new punctuation).
- Interpolation: `t('cost', { amount })` with `{amount}` in the message. Plurals: ICU, e.g. `"{count, plural, one {# card} other {# cards}}"`; Portuguese `"{count, plural, one {# carta} other {# cartas}}"`. Inside plural/select branches avoid a branch that is a single bare word in braces (e.g. `=0 {none}`): the parity test reads `{word}` as a placeholder; use `=0 {no cards}` style (with a space) instead.
- Bold/links inside sentences: `t.rich('key', { b: chunks => <strong>{chunks}</strong>, link: chunks => <Link href="/forge">{chunks}</Link> })` with `<b>…</b>` / `<link>…</link>` in the message. Keep the same tags in both languages.
- Translate every user-visible string: JSX text, `aria-label`, `title`, `placeholder`, `alt`, toast messages, button labels, empty states, confirm dialogs, error messages shown to the user, `document.title`/metadata.
- Numbers/dates: where code hardcodes `'en-US'` in `toLocaleString`/`Intl`, use the active locale (`useLocale()` from next-intl, or `useFormatter()`), keeping the same format options.
- `&apos;` / `&quot;` in JSX become plain `'` / `"` inside JSON.
- Keep behaviour, layout, classes and structure identical. Only text moves.

## Not in the screen rounds (game data in src/lib, translated in part 3)
Pack names and descriptions, rarity names (Common, Uncommon, Rare, Epic, Legendary), programming language names, mission descriptions, achievement names/descriptions, passive/ability names and texts, card titles/flavor text, rank/league names that come from lib constants, player and developer names, values from the API. Product names: GitGacha, BITS stay as is.

## Portuguese style (pt-BR)
Informal and friendly, "você". Short, like a mobile game. Use these terms consistently:
- pack → pack (plural packs); booster → booster; Gacha → Gacha; card → carta; deck/team → time; collection → coleção; inventory → inventário; store/shop → loja
- Forge → Forja; invoke/invocation → invocar/invocação; fragments → fragmentos; wildcard → coringa; Shiny → Shiny; duplicate → repetida
- battle → batalha; Arena → Arena; league → liga; Ranked → Ranked; rating → rating; rank → elo; season → temporada; Tower → Torre; Sprint → Sprint; challenge → desafio
- stamina → stamina; loyalty → lealdade; training → treino; level → nível; level up → subir de nível; XP → XP
- missions → missões; daily reward → recompensa diária; streak → sequência; pity → garantia ("Legendary garantido em N packs")
- claim → resgatar; open → abrir; buy → comprar; reroll/swap a mission → trocar; share → compartilhar; wishlist → lista de desejos
- friends → amigos; profile → perfil; achievements → conquistas; title → título; frame → moldura; sets → coleções/sets
- "Dev of the Week" → "Dev da Semana"; "Weekly Event" → "Evento semanal"; "Getting started" → "Primeiros passos"

## Verify before finishing (all must pass)
1. `npx tsc --noEmit` → no errors.
2. `node --import tsx --test src/i18n/messages.test.ts` → passes (same keys and placeholders in both languages, no empty Portuguese).
3. `npx eslint <your files>` → no NEW errors compared with before your change (the repo has an error budget; e.g. don't add `any`, unused vars, or setState-in-effect).
4. Search your files for leftover English UI text (e.g. `grep -nE ">[A-Z][a-z]+( [a-z]+)*<|(aria-label|title|placeholder)=\"[A-Z]"`) and convert what is user-facing.
